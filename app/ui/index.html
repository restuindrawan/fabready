    pcbcheck
    Preview

    Check a PCB before you order it

    Open a KiCad project folder or drop it here. pcbcheck checks routing, fab limits and the board outline, plus extra checks for keyboards, then re-checks every time you save in KiCad.

    Connect AI agents

    This app is also an MCP server. Connected agents can check the board, see it, apply pcbcheck's automatic fixes (list_fixes, apply_fix) and fix the rest by editing your KiCad files, while the app re-checks after every save. Each finding's Ask agent button copies a ready-made prompt.
