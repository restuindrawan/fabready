    Check a PCB before you order it

    Open a KiCad project folder or drop it here. fabready checks routing, fab limits and the board outline, plus extra checks for keyboards, then re-checks every time you save in KiCad.

    Connect AI agents

    The Agent tab chats with Claude Code, Codex or OpenCode right here. If you'd rather use your own terminal or editor, this app is also an MCP server: connected agents can check the board, see it, apply fabready's automatic fixes (list_fixes, apply_fix) and fix the rest by editing your KiCad files, while the app re-checks after every save.
